# Agentic Coding Evals 2025-2026 (synced seed)

Verified patterns from the XRAI knowledgebase:

- Minimal agent loop: a small shell-oriented tool surface plus linear history is easier to reproduce and debug.
- Reliable evaluation: deterministic builds, valid tests, clear issue specs, flake policy, and regression checks.
- Goal-oriented evals: measure improvement across rounds, not just one-shot completion.
