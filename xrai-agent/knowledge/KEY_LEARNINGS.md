# XRAI Key Learnings (synced seed)

- Keep scoring simple, debuggable, and easy to iterate.
- Prefer native primitives over custom daemon proliferation.
- Use feedback loops that are evidence-driven, not vibes-driven.
- Extract knowledgebase signals into reusable structured context.
- XRAI is a cross-platform AI + spatial ecosystem, but agent infrastructure should remain modular and small.
